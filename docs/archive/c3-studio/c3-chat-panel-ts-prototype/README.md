# Archived C3 Chat Panel TypeScript prototype

This directory preserves the older TypeScript/Tailwind chat-panel prototype and
its three direct center-view consumers for historical reference. It is not an
IntentSmith source root, build input, package export or implementation guide.

The prototype had 16 chat-panel source files and could not reproduce the much
larger committed runtime that C3 Studio actually loads. The active source
contract is documented in
[`c3-ide/extensions/c3-chat-panel/README.md`](../../../../c3-ide/extensions/c3-chat-panel/README.md).

The adjacent setup and visual documents are archived with the prototype because
they describe imports and build steps that are no longer valid. Do not restore
them to an active build without a separately approved, behavior-preserving
migration and a real Electron journey.
