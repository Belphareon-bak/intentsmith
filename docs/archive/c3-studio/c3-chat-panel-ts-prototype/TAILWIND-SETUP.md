# 🎨 Tailwind CSS + Aceternity UI Setup

## ✅ Co jsem vytvořil:

1. **tailwind.config.js** - Tailwind konfigurace s C3 barvami
2. **postcss.config.js** - PostCSS config pro Tailwind
3. **tailwind-plugins/glassmorphism.js** - Custom plugin pro glass efekty
4. **extensions/c3-chat-panel/src/browser/styles/tailwind-base.css** - Tailwind base
5. **lib/utils/cn.ts** - Utility pro merge class names

## 📦 Instalace závislostí

Otevřete VS Code terminál v root složce projektu a spusťte:

```bash
npm install -D tailwindcss postcss autoprefixer @tailwindcss/typography clsx tailwind-merge

# Nebo pokud používáte yarn:
yarn add -D tailwindcss postcss autoprefixer @tailwindcss/typography clsx tailwind-merge
```
