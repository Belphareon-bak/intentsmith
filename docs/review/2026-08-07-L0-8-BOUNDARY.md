## Shrnutí pro rozhodnutí

Porušení L0-8 je **jedna hrana a jeden symbol**, ne migrace. Obě varianty jsem
postavil a spustil; obě porušení ruší a obě vracejí identický výsledek jako
dnešní kód. Rozhodnutí tedy nestojí na ceně přechodu — ta je u obou malá — ale
na tom, co má hranice do budoucna umět.

Vedle toho sonda našla tři věci, které v zadání nebyly a rozhodnutí ovlivňují:
existující kontrola hranice má slepé místo přesně tam, kde porušení leží
(`L8-2`); nástroje specialisty existují v repozitáři **dvakrát bajtově identicky**
(`L8-3`); a `src/expertises/tools/**` nemá v `src/**` jediného konzumenta (`L8-4`).

### 1.2 Co přesně se přes hranici přenáší

Symbol je jediný: `ToolAdapter` (`src/expertises/tool-adapter.js:23`).

**`tool-adapter.js` má nula importů.** 154 řádků, žádná závislost na `src/**`,

To je pro rozhodnutí zásadní: hranice **nic dalšího netáhne**. Obava, že se
přes SDK vytáhne půl core, je v tomhle případě neopodstatněná.

Konzumovaný povrch je také malý — `adapters.js` má 5 tříd a všechny používají
jen `extends ToolAdapter`, `super(config)` a override `execute()` /

## 2. Nález `L8-2` — kontrola hranice má slepé místo přesně tam, kde je porušení

`specialist-loader.js:521-531` už kontrolu core importů má:

```js
// v121 2d: Plugin stability contract — warn on core imports (static analysis)
const entryContent = fs.readFileSync(entryPath, 'utf-8');
const coreImportPattern = /from\s+['"]\.\.\/\.\.\/src\//g;
const matches = entryContent.match(coreImportPattern);
if (matches) {
  logger.warn('SpecialistLoader',
    `${id}/index.js imports from core (../../src/) — ... ` +
    'Specialists should use ctx.registries instead. This will become an error in a future version.');
}
```

Má dvě díry a obě jsou aktivní:

1. **Čte jen `manifest.entry`**, tedy `index.js`. Skutečné porušení je
   v `adapters.js`, který entry point není — `index.js` ho jen importuje.
2. **Vzor `from\s+...` nechytá JSDoc** tvar `import('../../src/...')`, kterým
   jsou zapsané tři zbylé výskyty.

Změřeno aplikací téhož vzoru na entry pointy všech pěti balíčků:

```
accountant-cz: 0 zásahů v ./index.js
code-reviewer: 0 zásahů v ./index.js
dummy-logger:  0 zásahů v ./index.js
sazeni:        0 zásahů v ./index.js
translator:    0 zásahů v ./index.js
CELKEM varování, která loader dnes vypíše: 0
```

**Loader dnes nevypíše ani jedno varování, přestože porušení existuje.** Kontrola
vypadá jako zavedená a nechrání nic.

Dále: `tests/accountant-self-contained.test.js` navzdory názvu netestuje import
hranici — ověřuje, že `register(ctx)` se navěsí přes registries (24 testů).
**Žádný test dnes L0-8 nevynucuje.**

Oprava slepého místa je nutná **u obou variant** a je na nich nezávislá.

### 3.2 Co variantu A dělá levnější, než vypadá

`buildToolDefinitions()` **už je funkce** volaná až uvnitř `register(ctx)`
(`index.js:329` a `:370`), ne modulová konstanta. Adaptéry se tedy instancují
lazy, až když `ctx` existuje. Kdyby byly v modulové konstantě, musela by se
přepsat celá inicializace balíčku.

### 3.3 Běh

```
status: ok | net: 735892 | tax: 114108
clarify: clarify ["gross_income"]
```

Shodné s baseline. Pozitivní i negativní (clarify) cesta prošly.

### 3.4 Otevřené otázky varianty A

- **Kontrakt je implicitní.** `ctx.ToolAdapter` nemá verzi. Balíček nemá jak
  vyjádřit „potřebuji ToolAdapter s `validateResult`". Pole `engine` v manifestu
  (dnes `>=121.0.0`) je jediný existující nástroj a je hrubý.
- **JSDoc reference neřeší.** Tři typové odkazy z `§1.1` zůstávají.
- **Cena roste s počtem symbolů.** Každý další symbol v hranici znamená rozšířit
  `ctx` i signaturu factory ve všech balíčcích.
- **Factory obal je povinný.** `class X extends Injected` nelze na modulové
  úrovni; každý soubor s adaptéry se musí obalit.

## 4. Prototyp B — veřejné verzované extension SDK

### 4.1 Tvar

```
packages/specialist-sdk/
  package.json     { "name": "@intentsmith/specialist-sdk", "version": "1.0.0",
                     "type": "module", "exports": { ".": "./index.js" } }
  tool-adapter.js  ← kopie beze změny (0 importů, přenositelná as-is)
  index.js         export { ToolAdapter } from './tool-adapter.js';
```

Core drží jedinou identitu třídy re-exportem:

```js
// src/expertises/tool-adapter.js
export { ToolAdapter } from '@intentsmith/specialist-sdk';
```

Rozlišení přes npm workspaces (`"workspaces": ["packages/*"]`).

### 4.2 Diff v balíčku — jeden řádek

```diff
-import { ToolAdapter } from '../../src/expertises/tool-adapter.js';
+import { ToolAdapter } from '@intentsmith/specialist-sdk';
```

### 4.3 Běh

```
status: ok
net: 735892 tax: 114108
clarify: clarify ["gross_income"]
core.ToolAdapter === sdk.ToolAdapter : true
```

Shodné s baseline. Identita třídy je jediná i po rozdělení — re-export ji
nezdvojuje. (Dnes to nikdo netestuje: `grep -rn "instanceof ToolAdapter"` nemá
zásah, takže na tom aktuálně nic nestojí. Pro budoucí `instanceof` v CRE nebo
v tool executoru to ale platit musí.)

### 4.4 Otevřené otázky varianty B

- **Kde SDK fyzicky žije a jak se distribuuje.** Workspace uvnitř repozitáře je
  nejlevnější, ale balíček třetí strany z marketplace ho musí umět rozlišit —
  to je otázka pro `src/marketplace/package-installer.js`, ne pro SDK samotné.
- **Verzování se stává závazkem.** Jakmile SDK vyjde, jeho breaking change je
  breaking change pro cizí balíčky. To je přesně ta vlastnost, kvůli které se
  varianta volí — ale je to trvalý náklad.
- **`npm ci` a lockfile.** Přidání workspace mění instalační strom; dotýká se
  toho, co řeší `WP-M5-PACKAGE`.

## 7. Nález `L8-4` — `src/expertises/tools/**` nemá v `src/**` konzumenta

Hledání importu kterékoli z pěti funkcí uvnitř `src/**` vrací jediný zásah, a ten
míří jinam (`src/server.js:139` → `./tools/registry.js`, globální tool registry).

Runtime cesta vede přes kopii v balíčku. Core kopii dnes drží naživu **jen testy** —
včetně `tests/accountant-e2e.test.js`, který navzdory názvu „e2e" importuje
`src/expertises/tools/*`, tedy větev, kterou produkt při běhu nepoužívá.

To je disposition otázka (`RETAIN` / `RETIRE`) a patří operátorovi. Sonda ji
nerozhoduje, jen ji pojmenovává, protože mění, co znamená „specialista je
soběstačný".

## 9. Co sonda nerozhodla

- **Volbu varianty.** A i B fungují a obě porušení ruší.
- **Disposition duplicitních nástrojů** (`L8-3`) a core kopie bez konzumenta (`L8-4`).
- **Jestli se JSDoc typové odkazy počítají jako porušení L0-8.** Doslovné znění
  invariantu (*„žádný `import ../../src/`"*) je porušují; runtime hranici ne.
  Odpověď mění rozsah varianty A.
- **Kdy se opraví slepé místo kontroly** (`L8-2`). Je to nutné u obou variant,
  ale je to zapisující práce a nemá vlastníka.
