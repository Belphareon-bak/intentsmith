## Autoritativní boundary

HTTP zachovává první loopback/Host/Origin hranici. Za exact `matchRoute()` a
před každým handlerem nyní běží jeden `authorizeGlobalRequest()`:

- veřejné jsou jen `GET /`, `GET /health` a `GET /api/health`;
- Studio pro přesný backend origin používá existující private per-process
  capability, nikoli admin secret v rendereru;
- admin/CLI může použít timing-safe admin token;
- vydané API tokeny procházejí existujícím hash/expiry read modelem a potřebují
  `read`, `write`, `approve`, `admin`, `*` nebo exact route scope;
- produkční chybějící či neplatný credential vrací 401
  `INTENTSMITH_AUTH_REQUIRED`; platná identita bez scope vrací 403
  `INTENTSMITH_AUTH_SCOPE_REQUIRED`;
- více současně předložených credentialů fail-closed končí typed 400;
- non-production loopback bypass je explicitní a produkční větev jej nemá.

WS nejprve aplikuje stejnou local-access boundary a poté stejnou credential
autoritu. Úspěšný verify callback vloží immutable subject do serverového
requestu a session adapter dostane pouze tento subject. Žádné `chat`, `control`
ani `terminal` pole jej nemůže přepsat. Produkční native loopback handshake bez
credentialu vrací 401; Studio capability a bearer subprotocol jsou podporované.
