## Produkční autorita podle typu extension

- **Expertise:** instalace sama neroutuje; až explicitní enable zpřístupní
  definici a deterministicky změní výběr. Disable a remove vliv odstraní.
- **Skill:** trigger je připnutý, vstupy jsou typované a filesystem write nemá
  přímé FS API. Přesný `file.write` jde přes M2 Tool/Effect broker a single-use
  approval grant; obecné potvrzení nestačí.
- **Specialist:** balíček nesmí importovat interní `src/**`, effectful Node
  builtin, libovolný third-party bare modul ani použít detekované ambientní
  effect API. Code-review specialista čte pouze token-bound M2 ProjectContext.
- **Agent extension:** nativní M3 manifest smí použít pouze ProjectContext
  source a lokální `store`, `mark_seen` nebo non-LLM `in_app notify`. HTTP,
  webhook, model a jiné ambientní authority jsou odmítnuté před instalací.
- **MCP:** žádný produktový producent nebyl přidán; volitelný experiment je
  pravdivě odložen rozhodnutím 031 a M3 netvrdí MCP podporu.

## Lifecycle

Specialistu i nativního agenta lze instalovat jako disabled, explicitně
zapnout, vypnout a odebrat. Specialist uninstall odmítne busy instanci, odpojí
expertise vazby a zapíše durable tombstone, takže discovery balíček samovolně
neoživí. Explicitní reinstall znovu ověří package a migrace, ale ponechá jej
disabled do samostatného enable. Disabled nebo removed extension se neroutuje a
nevytvoří nový efekt.

## Přiznané hranice pro review

1. Package scanner je fail-closed statická hranice pro podporované M3 balíčky,
   nikoli bezpečnostní sandbox proti libovolně obfuskovanému nepřátelskému JS.
   Silnější runtime sandboxing zůstává vhodné M5 hardening téma.
2. Legacy non-extension agent definitions stále vlastní historické HTTP/RSS,
   webhook a externí notification cesty. Nativní M3 agent extension je pod
   novou policy, ale stará platforma nebyla migrována na M2. Operátorské review
   musí výslovně rozhodnout, zda roadmapové „všechny efekty agentů“ znamená
   pouze M3 extension producenty; pokud znamená i legacy engine, verdict musí
   být `CHANGES_REQUESTED`.
3. Skill cancel mezi vydáním a revokací single-use grantu má již přiznaný race:
   při mezitímním consume vrátí `EFFECT_EXECUTION_IN_DOUBT`, nikdy false success.
4. MCP pilot je `DEFERRED / NON_BLOCKING`; žádná MCP readiness se netvrdí.
