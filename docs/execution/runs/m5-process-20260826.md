## Implementovaný řez

`process-sandbox-provider` nyní před durable start authority používá exact
`/usr/bin/prlimit` a instaluje konečné CPU/address-space/file-size/FD/core
limity. Installer ověřuje exact `bwrap` a `prlimit` jako povinný core Linux
toolchain.

Nový `process-recovery` nepoužívá PID jako autoritu. Signalizace celé process
group nastane jen po shodě boot ID, start time, leader PID a PGID. Durable
repository vystavuje outstanding process census a takeover jej musí vyprázdnit
před file/Git recovery. Úspěch nebo prokázaná předchozí smrt vytvoří
append-only termination event; nečitelná či nekonzistentní identita zastaví
recovery bez zápisu terminálu a bez rollbacku.

Server opakuje startup census po dočasném selhání, zatímco lifecycle surface
zůstává fail-closed. Stav censu nese počet pokusů, čas posledního pokusu a pouze
typový error code pro následnou diagnostiku.
