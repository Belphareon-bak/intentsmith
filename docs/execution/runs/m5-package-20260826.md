## Veřejný kontrakt

- `--profile=core` je výchozí podporovaný Linux profil: backend, C3 Studio,
  Electron ABI a artifact smoke; PDF Python/fonty nejsou kritická podmínka.
- `--profile=full` explicitně vyžaduje a instaluje hash-locked PDF runtime;
  chybějící Python, `venv`, font nebo wheel fail-close zastaví instalaci.
- `--verify-only` provede read-only preflight před jakoukoliv instalací,
  buildem, downloadem nebo runtime sondou.
- `--offline` zakazuje Corepack network bootstrap, použije cache-only `npm ci`
  a frozen Yarn a nesondí Ollamu.
- `--minimal` a `--full` si zachovávají původní model-pull význam.

Docker není podporovaná M5 instalační cesta. Všechny Compose služby jsou
za explicitním profilem `unsupported`, listener zůstá `127.0.0.1`, lockfile
nemá `npm install` fallback a dokumentace jej nesmí prezentovat jako deployment.
