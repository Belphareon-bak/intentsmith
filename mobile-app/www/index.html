Gateway není dostupná

Aplikace se nedokázala spojit s http://127.0.0.1:3336. To znamená, že spojení do počítače nestojí — ne že by se něco pokazilo v samotném IntentSmithu.

  1. Na počítači běží gateway: npm run mobile:gateway
  2. Telefon je připojený USB kabelem a má povolené ladění
  3. Na počítači běží přesměrování: npm run mobile:android:reverse

Dokud spojení nestojí, aplikace neukazuje nic ze své paměti. Je to záměr: stará kopie schránky by se nedala odlišit od klidu.
