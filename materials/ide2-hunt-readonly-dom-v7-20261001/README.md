# Accepted GPU/model display probe V7 — archival sources

This directory contains 19 exact `.mjs` source blobs (105,388 B) from the
frozen V7 packet. `SOURCE-EXPORT-MANIFEST.json` binds every source blob to
its original hash and the source/physical review receipts. This publication
does not register another test suite or change product code.

## Accepted scope

One real packaged IDE run, 2026-10-01 18:55:11.326–18:55:41.123 UTC, passed
independent `QUALIFIED_PHYSICAL_REVIEW_PASS`. It verified seven native pointer
actions with hit tests, provider identities/sizes/digests for 14 models,
84 applicable evaluation rows with absent grades, seven unmeasured roles,
76 estimated candidates, and canonical 24 GiB GPU **capacity**. Capacity
does not state current free VRAM or inference readiness. The private fresh DB
contained no accepted grades; this does not certify production scoring.

The private uninstalled Hunt response was expected `503 DESKTOP_NOT_INSTALLED`.
Installed Hunt, accepted grader, model quality, CHAT, mobile and whole release
are not qualified by this probe. It forwarded only 16 bodyless metadata GETs
and no inference or provider writes. Inner startup POST `/api/show` was denied
before the host relay. Final owned namespace was strictly `after=[]`, with
normal child exit, acknowledged cleanup and both relay drains zero. Three
intermediate owned Z processes remained in evidence until init teardown.
Earlier V3/V4/V5/V6 whole FAIL results remain preserved.

## Sources and reproduction limits

- `host.mjs`, `probe.mjs`, `gpu-capture.mjs`: isolated physical observation;
- `pid-namespace-supervisor.mjs`, `namespace-init.mjs`, `relay-owned.mjs`:
  kernel process lifetime, ownership handshake and request cleanup;
- DOM, proc, cleanup, network and namespace controls: accepted guard sources;
- `common.mjs`, `package-members.mjs`: source/package identities.

Machine-specific `CONFIG.json`, binaries, dependencies, private DB, raw
provider/API responses, screenshots, runtime logs and Xauthority are excluded.
No secret or captured credential is included. The unchanged `common.mjs`
expects CONFIG beside these sources, so this archive is intentionally not
an executable fresh-clone runner. It must not be silently supplied with a
different configuration and reuse the old qualification.

The original run pins backend `34cfc198`, stage `483fb2d9`, package source
`45caf5b5` and AppImage SHA `40b016d0…aed57`; full identities are in the
export manifest. Equivalence was checked for 12 relevant product paths,
not for the whole backend. A relocated or adapted run requires fresh source,
configuration, ownership, package and environment review. Publication copying
does not rerun browser/backend/provider/GPU/DB or alter the private packet.
