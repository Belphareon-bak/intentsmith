### Plán Implementace TODO CLI Aplikace v Node.js

#### 1. Nastavení Projektu
- **Krok 1:** Vytvoření nového Node.js projektu pomocí `npm init -y`.
- **Krok 2:** Installování potřebných modulů, jako je `fs` pro práci soubory a `commander` pro parsování argumentů.

#### 2. Struktura Souborů
- **Soubor hlavní aplikace:**
  - `/tmp/workflow-auto/todo.js`: Obsahuje logiku CLI aplikace.
- **Soubor pro ukládání úkolů:**
  - `/tmp/workflow-auto/tasks.json`: Ukládá seznam úkolů ve formátu JSON.

#### 3. Definice Úkolu
- **Struktura každého úkolu:**
  ```javascript
  {
    id: number,
    text: string,
    done: boolean,
    createdAt: string // Formát ISO 8601
  }
  ```

#### 4. Implementace Funkcí

##### a) Přidání Úkolu (`add <text>`)
- **Krok 1:** Získání textu úkolu z argumentů.
- **Krok 2:** Generování unikátního `id` pro úkol (může být následující po posledním ID v souboru).
- **Krok 3:** Získání aktuálního času pro `createdAt`.
- **Krok 4:** Načtení existujících úkolů z `tasks.json` nebo inicializování prázdného pole.
- **Krok 5:** Přidání nového úkolu do pole a uložení změn zpět do souboru.

##### b) Výpis Úkolů (`list`)
- **Krok 1:** Načtení úkolů z `tasks.json`.
- **Krok 2:** Formátovaný výstup každého úkolu:
  - Číslo (index + 1).
  - Označení `[x]` pro hotové, `[ ]` pro nehotové.
  - Text úkolu.
- **Krok 3:** Pokud jsou žádné úkoly, výpis hlášky "Žádné úkoly."

##### c) Označení Úkolu jako Hotový (`done <id>`)
- **Krok 1:** Získání `id` z argumentů.
- **Krok 2:** Načtení úkolů z `tasks.json`.
- **Krok 3:** Najít úkol s daným `id`.
  - Pokud nenajděte, výpis hlášky "Úkol nebyl nalezen."
- **Krok 4:** Změna hodnoty `done` na `true`.
- **Krok 5:** Uložení změn do souboru.

#### 5. Parsování Argumentů
- **Použití modulu `commander`:**
  - Definování příkazů (`add`, `list`, `done`).
  - Nastavení parametrů a popisů pro každý příkaz.
  - Implementace funkcí pro každý příkaz.

#### 6. Správa Souborů
- **Načtení úkolů:**
  ```javascript
  const tasks = JSON.parse(fs.readFileSync(tasksPath, 'utf8'));
  ```
- **Uložení úkolů:**
  ```javascript
  fs.writeFileSync(tasksPath, JSON.stringify(tasks, null, 2));
  ```

#### 7. Zpracování Chyb
- **Ošetření chyb při čtení/saving souborů:**

  - Výpis uživatelsky přijatelných chybových hlásek.

#### 8. Testování

- **Krok 3:** Přidání a výpis několika úkolů pro kontrolu formátovaného výstupu.
